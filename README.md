## Outcome

The cleaned Netflix dataset was transformed into an interactive Power BI dashboard that enables quick analysis of Netflix content using charts, filters, and visualizations.

The dashboard provides analysis of:

- Movies vs TV Shows
- Genres
- Shows by Country
- Ratings
- Release Year
