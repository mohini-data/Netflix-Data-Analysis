# Netflix Data Analysis Using Python & Power BI

## Project Overview

This project focuses on analyzing Netflix movies and TV shows using Python and Power BI. Python was used for data cleaning and preparation, while Power BI was used to create an interactive dashboard and visualize the data.

## Tools & Technologies

- Python
- Pandas
- Power BI
- CSV Dataset
- Jupyter Notebook

## Analysis Performed

The project analyzes:

- Movies vs TV Shows
- Genres
- Shows by Country
- Ratings
- Release Year

## Project Workflow

Raw Netflix Dataset → Data Cleaning using Python → Cleaned Dataset → Power BI → Data Visualization → Dashboard → Insights

## Dashboard

The Power BI dashboard presents Netflix content through interactive charts, cards, and filters, making it easier to understand the distribution and patterns in the dataset.

## Objective

The main objective of this project is to understand Netflix's content distribution and identify useful patterns and insights through data analysis and visualization.

## Key Skills Demonstrated

- Data Cleaning
- Data Analysis
- Data Visualization
- Python & Pandas
- Power BI
- Dashboard Creation
- Insight Generation
